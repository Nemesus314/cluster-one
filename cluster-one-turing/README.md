# Cluster One — Turing

*Installer and checker in one: installs Cluster One as a set, unpacks, checks, and touches the node only once the whole set fits.*

Version 4.0.6 · WordPress 7.0+ (getestet mit 7.1 / tested up to 7.1) · PHP 7.4+ · GPL-2.0-or-later

## Deutsch

Installer und Prüfer in einem: spielt Cluster One als Satz auf, entpackt, prüft, und fasst den Knoten erst an, wenn der ganze Satz zusammenpasst.

**Installation:** diesen Ordner `cluster-one-turing` nach `wp-content/plugins/` legen und aktivieren, oder den ganzen Satz mit Turing aufspielen (siehe das README eine Ebene höher). Die Übersetzung liegt in `languages/` und wird vom Plugin selbst geladen.

**Stand:** Turing ist ein Werkzeug neben der Suite und liegt nur hier auf GitHub; für das Verzeichnis ist die Ausgabe Turing Diagnostics bestimmt.

**Mehr:** `readme.txt` (WordPress-Format), `why.txt` (warum es das gibt).

## English

Installer and checker in one: installs Cluster One as a set, unpacks, checks, and touches the node only once the whole set fits.

**Install:** put this folder `cluster-one-turing` into `wp-content/plugins/` and activate it, or install the whole set with Turing (see the README one level up). The translation lives in `languages/` and is loaded by the plugin itself.

**Status:** Turing is a tool beside the suite and lives only here on GitHub; the edition meant for the directory is Turing Diagnostics.

**More:** `readme.txt` (WordPress format), `why.txt` (why it exists).
