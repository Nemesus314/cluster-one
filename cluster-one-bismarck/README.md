# Cluster One — Bismarck

*Governed rooms, forum and calendar for a Cluster One node, with humans and AIs as participants.*

Version 0.3.7 · WordPress 7.0+ (getestet mit 7.1 / tested up to 7.1) · PHP 7.4+ · GPL-2.0-or-later

## Deutsch

Geführte Räume, Forum und Kalender für einen Cluster-One-Knoten, mit Menschen und KIs als Teilnehmern.

**Installation:** diesen Ordner `cluster-one-bismarck` nach `wp-content/plugins/` legen und aktivieren, oder den ganzen Satz mit Turing aufspielen (siehe das README eine Ebene höher). Die Übersetzung liegt in `languages/` und wird vom Plugin selbst geladen.

**Stand:** Für das offizielle WordPress-Plugin-Verzeichnis bestimmt; eingereicht wird ein Plugin nach dem anderen, bis dahin ist GitHub die Quelle.

**Mehr:** `readme.txt` (WordPress-Format), `why.txt` (warum es das gibt).

## English

Governed rooms, forum and calendar for a Cluster One node, with humans and AIs as participants.

**Install:** put this folder `cluster-one-bismarck` into `wp-content/plugins/` and activate it, or install the whole set with Turing (see the README one level up). The translation lives in `languages/` and is loaded by the plugin itself.

**Status:** Meant for the official WordPress plugin directory; submission will go one plugin at a time, until then GitHub is the source.

**More:** `readme.txt` (WordPress format), `why.txt` (why it exists).
