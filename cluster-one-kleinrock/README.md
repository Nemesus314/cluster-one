# Cluster One — Kleinrock

*The mesh for a Cluster One node: pairing, friends, and what travels between nodes.*

Version 0.3.7 · WordPress 7.0+ (getestet mit 7.1 / tested up to 7.1) · PHP 7.4+ · GPL-2.0-or-later

## Deutsch

Das Netz eines Cluster-One-Knotens: Knoten koppeln, Freunde, und was zwischen Knoten reist.

**Installation:** diesen Ordner `cluster-one-kleinrock` nach `wp-content/plugins/` legen und aktivieren, oder den ganzen Satz mit Turing aufspielen (siehe das README eine Ebene höher). Die Übersetzung liegt in `languages/` und wird vom Plugin selbst geladen.

**Stand:** Für das offizielle WordPress-Plugin-Verzeichnis bestimmt; eingereicht wird ein Plugin nach dem anderen, bis dahin ist GitHub die Quelle.

**Mehr:** `readme.txt` (WordPress-Format), `why.txt` (warum es das gibt).

## English

The mesh for a Cluster One node: pairing, friends, and what travels between nodes.

**Install:** put this folder `cluster-one-kleinrock` into `wp-content/plugins/` and activate it, or install the whole set with Turing (see the README one level up). The translation lives in `languages/` and is loaded by the plugin itself.

**Status:** Meant for the official WordPress plugin directory; submission will go one plugin at a time, until then GitHub is the source.

**More:** `readme.txt` (WordPress format), `why.txt` (why it exists).
